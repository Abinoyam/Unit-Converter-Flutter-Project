# Experiment 08 — Animations

## Aim
To add animations and transitions to a Flutter unit converter.

## Features
- AnimatedSwitcher with fade and slide transitions for the result card.
- Unit conversion for meters, kilometers, centimeters, and miles.
- Unit swapping and input validation.

## Run
```bash
flutter pub get
flutter test
flutter run
```

## Example
100 Meters = 0.1 Kilometers.
