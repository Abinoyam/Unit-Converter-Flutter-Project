# WEEK-7 — Unit Converter

Flutter application for converting length, weight, and temperature.

## Features
- Length, weight, and temperature conversions
- Reusable `ConverterCard` and `UnitDropdown` widgets
- Light/dark theme toggle
- Conversion history with clear option
- Unit swapping
- Input validation and absolute-zero temperature validation

## Run
```bash
flutter pub get
flutter test
flutter run
```

History is kept in memory while the app is running and resets when the app restarts.
