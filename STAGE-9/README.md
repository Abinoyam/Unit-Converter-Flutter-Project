# Experiment 09 — REST API

## Aim
To retrieve and display JSON data from a REST API in Flutter.

## API used
Open-Meteo current weather endpoint for Hyderabad (no API key required).

## Concepts
- HTTP GET request using the `http` package.
- JSON decoding and model parsing.
- Loading, success, error, timeout, and retry states.

## Run
```bash
flutter pub get
flutter test
flutter run
```

If the request fails, check the emulator's internet connection and tap Try Again.
